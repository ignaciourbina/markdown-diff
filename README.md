# Markdown Diff

Compare two Markdown documents in the browser. Both documents run through a
normalization pipeline first (line endings, tabs, trailing whitespace, blank
lines, heading and list formatting, punctuation spacing), so formatting noise
does not read as change. The diff reports line-level entries with token-level
highlights, a unified diff, and a downloadable Markdown report.

Runs entirely client-side; documents are not uploaded anywhere.

**Live:** https://ignaciourbina.github.io/markdown-diff/

## Origin

TypeScript port of a Python tool (Streamlit + Flask). The diff engine is a
faithful port of `difflib.SequenceMatcher`, and the test suite includes a
parity fixture generated by the original Python implementation — the port
reproduces its output byte for byte, entry ids included
(`src/lib/__tests__/parity.test.ts`).

## Development

```
npm install
npm run dev        # local dev server
npm test           # vitest (32 tests, incl. Python-parity fixtures)
npm run build      # typecheck + production build
```

## Structure

- `src/lib/` — the engine: `sequencematcher.ts` (difflib port), `normalize.ts`,
  `diff.ts`, `tokens.ts`, `compare.ts`, `navigation.ts`, `report.ts`
- `src/components/` — the UI
- `src/lib/__tests__/` — ported test suite + parity fixtures
